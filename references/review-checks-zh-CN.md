# 边界判定与 PDF 验收

## 边界判定

1. **按得分能力判定。** 用用户指定的大纲或教材小节列出具体考点。逐小问读 QP 的作答要求和对应的官方 MS，判断得分是否要求使用、解释或实现该考点。题目所属的大题标题、背景和关键词用于定位。相同词语出现在题干里、作答时顺带使用某个结构、或 MS 把它列为可替代方法时，仅凭这些信号不足以收录。
2. **混合小问。** 小问只要直接考到范围内的能力，就检查能否从同一题中独立分出作答要求和对应分值。可独立作答和给分的部分分别归类。不可独立拆分的计分小问保留整道小问及对应 MS，记下它涉及的其他考点。同样的判断依据也适用于披着另一专题背景的题。
3. **上下文和依赖。** 区分「知道题面给出的定义、接口或数据」和「需要用前一小问得到的结果或实现」。前者只摘必要原文并保留图表。后者连同必需的前置小问和官方 MS 一起保留。逐项检查保留题真正调用了哪些方法、需要哪些已建立的数据结构、是否要求程序能运行或测试，并追溯这些前置小问自身所需的依赖。后续小问仅因使用已选题的结果，并不自动纳入范围。向原卷的官方附件核对实际输入文件和字节内容。题目要求考生新建的输出文件按原题处理。
4. **反查排除项。** 按纳入范围的原卷逐一清点有分值的小问，确保每个小问在内部清单有归类。用排除项和含多个专题的小问做第二遍核对，重点看评分点中出现的目标能力和选入项的近似题。相似题应使用同一条收录理由。不同年份或卷别的图表、条件、代码和数据变化也逐项确认。对仍有争议的边界题，记录原卷、小问号和采取的口径。

## PDF 验收

- **看版面。** 将最终 QP、MS 的裁剪范围与原页对照，逐项核对题干、符号、图表、作答区、代码、分值、附件及 MS 表格列和续页。渲染检查有风险的裁剪边界和每种版式的代表页，尤其是跨页图、扫描页、旋转页和新来源。
- **验文字层。** 在使用新来源或不同 PDF 处理方式前，验证从可见正文提取出的短句与页面一致。导出后对每种来源或处理方式的代表页，用实际题干和评分正文做一次复制或文本提取，并确认能用同一句搜索定位。封面、页眉和新增题号的测试不能替代正文。发现乱码或搜索失败时，逐页检查受影响的页。优先换用身份、内容与图表都核实为同卷的清晰原版。仅有扫描件时保留准确的可见原文，文字层能否可靠补充取决于 OCR 核对结果。交付时说明仍存在的搜索或复制限制。
- **核内容边界。** 当要求删除范围外内容时，检查 PDF 里真正保留的内容。仅给原页加可见裁剪框可能仍把整页藏在文件内部。可在独立副本上先移除裁剪范围外的内容，再嵌入或以其它方式生成边界准确的片段，同时尽量保留可用文字层。用文本读取和 PDF 对象检查验证代表性切口，确认未把范围外小问或评分行一起带入。
