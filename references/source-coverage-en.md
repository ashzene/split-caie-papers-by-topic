# Coverage and missing papers

## Cutoff and release dates

- Follow any cutoff date, year or exam series the user specifies. Otherwise use the current local date and time zone of the user's computer. Prefer the date and time zone supplied by the client, or read them on the user's computer. When running remotely, use the client date. Use the time zone to establish the date and the user's specified scope to determine exam regions. The newest paper on the Desktop describes the extent of local coverage.
- Use the official syllabus, exam calendar or timetable to identify the applicable series within scope. If the user gave no start year, use the request, existing material and the years in which the syllabus code applies to determine historical coverage. Extend that coverage to the current cutoff. Check for missing entire series as well as individual variants.
- Check separately whether a series took place, whether its official release date has arrived and whether the files can be obtained. Cambridge releases QP, MS and grade thresholds to the School Support Hub on results day for that series. Use the official date for the particular series. The public past papers page may offer a selection. [Cambridge release policy](https://help.cambridgeinternational.org/hc/en-gb/articles/32168220870162-When-will-the-latest-question-papers-and-mark-schemes-be-available-on-the-School-Support-Hub) · [Cambridge results dates](https://www.cambridgeinternational.org/exam-administration/results/)

## Expected inventory and matching

1. Build a separate inventory for each subject, exam year and series. Start with the component table in the official grade thresholds for that series. Use the applicable syllabus, timetable or a Cambridge paper index you can lawfully access to confirm which variants have actual QP/MS documents. Official tables already available locally are suitable. Check whether entry combinations, carry-forward marks, exemptions and portfolio codes correspond to actual exam papers. Mark the inventory as unverified if the evidence cannot be reconciled. [Cambridge guidance on component codes and variants](https://help.cambridgeinternational.org/hc/en-gb/articles/29564314813970-Why-do-some-component-codes-in-the-Cambridge-Guide-to-Making-Entries-and-timetable-not-match-the-component-numbers-in-the-syllabus)
2. Track QP and MS availability using the key `syllabus code + year + series + component/variant`. Compare each expected key with the local files. For example, 9618 Paper 3 had variants 31 and 32 in November 2021 and variants 31, 32 and 33 in November 2025. Verify the actual series and paper count for each year. [November 2021 9618 component table](https://www.cambridgeinternational.org/Images/645413-computer-science-grade-threshold-table-november-2021.pdf) · [November 2025 9618 component table](https://www.cambridgeinternational.org/Images/749702-computer-science-9618-november-2025-grade-threshold-table.pdf)
3. When online sources are permitted, fill gaps key by key for series and variants whose release date has arrived. Prefer Cambridge sources, and verify that files from public mirrors are the same original official documents. If the user restricts the task to local sources, use the official material already available and report the resulting coverage. Mark the expected inventory as unverified if official evidence is insufficient. Record whether a series has yet to take place, is awaiting release, has been released with material unavailable, or has insufficient information. Keep the inventory in the workspace and briefly report actual coverage and remaining QP/MS gaps with the delivery.
