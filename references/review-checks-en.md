# Scope and PDF checks

## Scope decisions

1. **Classify by the assessed skill.** List the concrete objectives from the syllabus or textbook sections the user specified. Read what each subquestion asks the candidate to do and what its official MS awards marks for. Include tasks whose marks require using, explaining, or implementing an in-scope skill. Use headings, scenarios, and keywords to locate candidates. A term appearing in the wording, incidental use of a structure, or an optional approach listed in the MS gives insufficient evidence on its own.
2. **Handle mixed subquestions.** When a subquestion directly assesses an in-scope skill, check whether its tasks and marks can be separated. Classify parts separately when each can be answered and marked independently. Keep an indivisible assessed part and its matching MS in full, and record the additional topics it touches. Apply the same criterion when the scenario belongs to a different topic.
3. **Preserve context and dependencies.** Distinguish given definitions, interfaces, or data from a result or implementation the candidate must obtain in an earlier part. Keep only the necessary verbatim context and figures for the former. Keep the required earlier subquestion and its official MS for the latter. Check the methods the retained task calls, the data structures it assumes, and whether it asks the candidate to run or test the program. Trace dependencies of any retained prerequisites as well. A later part that relies on an included question still needs its own scope decision. Verify the actual inputs and file bytes against the official support materials. Treat files the candidate is instructed to create as outputs.
4. **Review exclusions.** Inventory scored subquestions across the eligible papers and give every one a disposition in the internal manifest. Review exclusions and mixed-topic questions in a second pass. Look for marking criteria that assess the requested skill and for close counterparts to included questions. Apply the inclusion rationale consistently to those counterparts. Check differences in diagrams, constraints, code, and data across years or variants. For borderline decisions, record the paper, subquestion, and scope criterion used.

## PDF acceptance checks

- **Check the rendered pages.** Compare final QP and MS crops against the original pages. Verify the question wording, symbols, figures, answer space, code, marks, attachments, and relevant MS columns and continuations. Render high-risk boundaries and a representative page for each layout, especially across page breaks, scans, rotated pages, and new sources.
- **Check the text layer.** Before using a new source or processing method, extract a short phrase from visible body text and compare it with the page. In the exported PDF, test copying or extracting actual question and marking text and searching for the same phrase on representative pages for each source or processing method. Cover text, headers, and added question numbers do not substitute for testing body text. If text is garbled or search fails, check every affected page. Prefer another verified original of the same paper with matching content and figures. For scan-only sources, preserve accurate visible content and add a text layer only if OCR can be checked reliably. Report any remaining search or copy limitations.
- **Check what the crop retains.** When out-of-scope content is to be removed, verify the final PDF payload. A visual clip around an embedded source page can still retain the full source page internally. Remove material outside the crop on a separate copy before embedding, or use an equivalent bounded representation, while preserving usable text where possible. Verify representative cuts through text extraction and PDF object inspection to confirm that excluded questions or marking rows are absent from the output.
