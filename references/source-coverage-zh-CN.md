# 覆盖范围与缺卷核对

## 截止日期和发布

- 有明确截止日期、年份或场次时按用户指定。否则使用用户电脑的当前本地日期和时区。优先使用客户端提供的日期和时区，也可在用户电脑本机读取系统时间。远程运行时以客户端本地日期为准。时区用于确认日期，考试地区按用户指定范围判断。桌面最后一份卷子的年份只代表本地覆盖。
- 用官方 syllabus、考试日历或考试时间表列出请求范围内的适用场次。无明确起始年份时，用请求、既有资料和 syllabus code 的适用年份确定历史范围，并补齐到当前截止日期。整场缺失和个别卷别缺失都要检查。
- 分别确认场次是否开考、是否到了官方发布时间、文件能否取得。Cambridge 在对应场次出成绩当天向 School Support Hub 发布 QP、MS 和 grade thresholds。以当场的官方日期为准。公开的 past papers 页面可能只列出一部分。 [Cambridge 发布规则](https://help.cambridgeinternational.org/hc/en-gb/articles/32168220870162-When-will-the-latest-question-papers-and-mark-schemes-be-available-on-the-School-Support-Hub) · [Cambridge 成绩发布日期](https://www.cambridgeinternational.org/exam-administration/results/)

## 应有清单和配对

1. 每个科目、年份和场次分别建立清单。主要查该场官方 grade thresholds 中的 component 表，结合适用的 syllabus、考试时间表或能合法访问的 Cambridge 原卷索引，确认哪些是有实际 QP/MS 的卷别。可先用本地已有官方表。仅有报考组合、成绩结转、豁免、作品集等代码时，须核实是否对应实际考试卷。材料无法互相印证时把清单记为未核实。 [Cambridge 官方卷别说明](https://help.cambridgeinternational.org/hc/en-gb/articles/29564314813970-Why-do-some-component-codes-in-the-Cambridge-Guide-to-Making-Entries-and-timetable-not-match-the-component-numbers-in-the-syllabus)
2. 以 `syllabus code + 年份 + 场次 + component/variant` 为键记录 QP 和 MS 是否存在，逐键比较应有清单和本地资料。例子是 9618 的 2021 年 11 月 Paper 3 有 31、32，2025 年 11 月还有 33。场次和考试卷数按当年查证。 [2021 年 11 月 9618 component 表](https://www.cambridgeinternational.org/Images/645413-computer-science-grade-threshold-table-november-2021.pdf) · [2025 年 11 月 9618 component 表](https://www.cambridgeinternational.org/Images/749702-computer-science-9618-november-2025-grade-threshold-table.pdf)
3. 允许联网时，逐键补齐已到发布时间的场次和卷别，优先 Cambridge 官方来源，再核验公开镜像是否是相同的官方原版。若用户限本地，用已有官方资料核对并清楚注明覆盖。缺少足够的官方资料时，将应有清单标为未核实。分别记录未开考、待发布、已发布但未取得及信息不足。将核对清单留在工作区，并在交付消息简述实际覆盖和仍缺的 QP/MS。
